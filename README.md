# Daily Dish - Restaurant Website

A modern, highly interactive landing page for a premium restaurant featuring dark-mode luxury aesthetics, dynamic hover depth effects, and ambient video integrations.

## Preview
![Daily Dish Hero Preview](preview.jpg)

## Interactive Features
- **Hero Parallax:** Dragging your cursor across the main section dynamically adjusts image opacity and perspective.
- **Horizontal Auto-Sliding Menu:** Showcase of "Most Sold Items" featuring automated left-sliding card transitions.
- **Ambient Video Reservation:** Background video integration on the "Book a Reservation" section for an immersive dining feel.
- **Custom Social Media Styling:** Interactive footer icons with brand-tailored hover transitions (Facebook blue highlight, Instagram glow, etc.).
- **Responsive:** Responsive for various devices, like smartphones, and laptops etc.
